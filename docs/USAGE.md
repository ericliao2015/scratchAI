# BlockAI 使用說明

BlockAI 是以 TurboWarp（Scratch 3 的修改版）為基礎的積木程式編輯器，在右上角多了 **✨ AI 助手** 按鈕。

---

## 1. 第一次使用：設定 AI

1. 按右上角 **✨ AI 助手** → 切到 **設定**。
2. **平台**：選 Anthropic Claude、OpenAI、Google Gemini，或「OpenAI 相容」（Ollama 等本機模型）。
3. **API KEY**：貼上自己的 KEY（每個平台下方有取得 KEY 的連結）。
4. **模型**：貼上 KEY 後會自動選好該平台的高階模型；按「載入清單」可以看到這個 KEY 能用的所有模型。
5. 按 **測試連線**，出現「連線成功」就完成了。

### 額度用完怎麼辦？

在「額度用完時」選擇策略：

| 策略 | 說明 |
|---|---|
| 高階優先（預設） | 先用最好的模型；額度用完時自動改用中階、低階模型 |
| 固定模型 | 不自動切換 |
| 省錢優先 | 先用便宜的模型，答案有錯時才升級 |

可以同時設定多個平台的 KEY，某個平台全部不能用時會自動改用其他平台（可以關閉）。

### 班級閘道（不用自己的 KEY）

老師架好「班級閘道」（見 `server/README.md`）後，學生在 **設定 → 平台** 選 **班級閘道**，輸入老師給的網址、班級代碼和自己的座號即可；
老師的班級設定檔若含閘道資訊，套用後只要輸入座號。使用閘道時可以 **繳交給老師**（自我檢查分頁）和 **存到雲端**（設定分頁）。

### 本機模型（WebLLM）

平台選 **本機模型 WebLLM** 並勾選啟用：模型下載到電腦（約 1～3 GB，一次）後，AI 家教、解釋、提示可以離線使用。
需要支援 WebGPU 的瀏覽器（新版 Chrome、Edge）。小模型不夠聰明寫程式或批改，這些功能仍會使用其他已設定的雲端模型。

### KEY 安全

- 預設 KEY 只存在這個分頁，關掉就清除。勾選「在這台裝置記住 KEY」才會保存。
- **共用電腦不要勾選**；用完可以按「清除此裝置上的 KEY」。
- KEY 只會送到你選擇的 AI 平台，不會送到其他地方。

## 2. 學生：用 AI 產生積木

1. 切到 **產生積木**，用一句話描述想做的程式，例如：
   - 「讓角色用方向鍵上下左右移動」
   - 「做一個接蘋果遊戲：蘋果從上面掉下來，接到加 1 分」
   - 「把移動 10 步改成 5 步」（修改既有的積木也可以）
2. 按 **送出**。如果描述不夠清楚，AI 會先問你問題，點選答案即可。
3. AI 會說明它打算做什麼（新增哪些角色、腳本、變數），按 **套用到專案**。
4. 不滿意可以按 **復原這次變更**（或 Ctrl+Z）；積木太亂可以按 **整理積木**。

**自動測試**（預設開啟）：AI 會為它寫的程式附上一個小測試（例如「按綠旗、按右鍵後角色 x 變大」），
在背景用專案的複本實際執行幾秒（不影響你的專案），結果顯示為「🧪 已自動測試：2/2 項通過」。
測試沒通過時，AI 會依執行結果自動修正一次。可在輸入框下方取消勾選「自動測試」。

> 「設定 → 說明方式」可以選「簡易」（適合國小，AI 會先確認需求並用簡單的話解釋）或「進階」。

## 3. 學生：AI 生圖

1. 切到 **AI 生圖**（需要在設定填 Agnes AI 的 KEY）。
2. 描述想畫的角色或背景，選擇用途（角色造型／舞台背景）與風格。
3. 勾選後製選項：去背、自動裁切、置中、縮放、左右翻轉、動畫造型（走路、跳）、轉向量圖、壓縮。
4. 按 **開始畫** → 預覽 → **加入造型**（加到目前角色或新角色）。

### AI 家教

**AI 家教** 分頁不會直接幫你寫程式：輸入目標後按 **給我提示**，最多三層（想法 → 用哪些積木 → 程式骨架）。
在積木上按右鍵可以選 **🤖 AI 解釋這段程式** 或 **🤖 AI：為什麼不會動？**；
後者會先在背景把你的程式跑 3 秒，把看到的情況（角色有沒有動、變數怎麼變、說了什麼）一起交給 AI 判斷。

### 任務（自學）

**任務** 分頁有一關一關的小任務（內建「入門任務包」），每個任務有說明、提示，按 **檢查** 會在背景實際執行程式確認。

- **自己完成**：照說明從頭寫。
- **積木排序**：按 **放上打散的積木**，把打散的積木拼回正確順序。
- **找錯誤**：按 **放上有問題的程式**，找出錯誤並修好。

提示先看老師寫的，用完後（老師有開放家教時）可以 **請 AI 家教給提示**。進度記在這台電腦，完成的任務會寫進專案的 AI 使用紀錄。
**🤖 AI 出題**：輸入想練習的主題並選題型，AI 會出一題（含檢查條件），放進「我的練習」任務包。

## 4. 學生：自我檢查

切到 **自我檢查**，選老師提供的範本（或自己輸入標準，一行一項），按 **開始檢查**。
點結果下方的積木標籤，會跳到並標示相關的積木。能看到多少細節由老師決定。

## 5. 老師模式

**設定 → 模式**：第一次輸入的 PIN 會成為老師 PIN。進入老師模式後多了 **批次** 與 **範本** 兩個分頁。

### 批改範本

**範本 → 新增範本**，每個項目可以是：

- **規則**（程式判斷，免費、結果固定）：例如使用某個積木、有某個變數、角色數量、廣播有送出也有接收、使用迴圈／條件、使用擴充（如畫筆）……
- **執行測試**（免費、結果固定）：在背景用模擬操作實際執行學生的程式，再檢查結果，依通過的條件比例給分。例如：
  ```json
  {"duration": 3,
   "actions": [{"at": 0, "do": "greenFlag"}, {"at": 1, "do": "keyPress", "key": "right arrow"}],
   "expect": [{"sprite": "Cat", "prop": "x", "op": "increased"}, {"var": "分數", "op": ">=", "value": 1},
              {"said": "你好"}]}
  ```
  操作：greenFlag、keyPress／keyDown／keyUp（key）、click（sprite）、clickStage、broadcast（message）、
  answer（text，回答「詢問並等待」）、mouse（x、y、down）。
  檢查：角色屬性（x、y、direction、size、visible、costume、clones）、變數（var）、背景（prop: backdrop）、說話（said）；
  比較：= != > >= < <= changed unchanged increased decreased contains；`at` 指定第幾秒（預設結束時）。
  時間是模擬的，3 秒的測試不到 1 秒就跑完。
- **AI 判斷**：描述程式的行為，例如「碰到蘋果時分數加 1」。

範本設定：

- **計分方式**：分數，或通過／不通過（可設定「通過幾項算通過」）。
- **學生可見度**：完整（結果、評語、積木標示）／只看每項結果／只看通過幾項／不開放自我檢查。
- **評語語氣**：給學生（鼓勵、提示方向、不給答案）或給老師（精確）。

也可以把作業要求整段貼到「用文字產生範本」，AI 會整理成範本草稿，修改後再儲存。範本可以匯出／匯入 JSON。

### 批次批改

1. **批次 → 批次批改**，選擇作業檔案（可一次選多個 .sb3，或整個 .zip）。建議檔名 `座號_姓名.sb3`。
2. 選範本，按 **開始批改**。
3. 完成後按 **下載報告（zip）**，內容包含：
   - `reports/座號_姓名.md`：每位學生一份批改紀錄
   - `summary.csv`：全班總表（Excel 可直接開啟）
   - `results.json`：完整資料
4. 勾選「模型需要降級時先暫停」時，若額度用完會先暫停，確認後才改用較低階模型，避免同一批作業被不同模型批改。

送給 AI 的內容只有程式本身，**不包含檔名或姓名**。

### 批次修改

1. **批次 → 批次修改**，選擇檔案並描述修改內容，例如「每份都加入按空白鍵跳躍的程式」。
2. 選擇方式：
   - **統一修改**：AI 以第一份為範例產生一次修改方式，再套用到每一份（便宜）。先按「先用第一份預覽」確認。
   - **個別修改**：AI 依每份作業內容分別修改（每份呼叫一次 AI）。
3. 下載 `修改結果_日期.zip`：修改後的 .sb3、每份的變更紀錄與 `changes.csv`。**原始檔案不會被更動**。
4. 可以直接按「接著批改修改後的檔案」。

### 班級分頁（班級閘道管理）

老師模式的 **班級** 分頁：連線到班級閘道 → 新增班級（模型、每人每日額度）→ 取得班級代碼；
可查看每位學生近 7 天用量、下載繳交的作業，或 **全部送到批次批改**。

### 任務包

在 **任務** 分頁用 **🤖 AI 出題** 或 **匯入任務包** 準備題目，**匯出任務包** 可以分享 JSON。
班級設定檔可勾選要包含的任務包，學生套用班級設定後就會在任務分頁看到。任務包格式見 `src/ai/missions/pack.js`。

### 班級設定檔

**範本 → 班級設定檔**：設定班級名稱、考試模式、允許的功能與平台、每人每天生圖上限、學生預設說明方式，以及給學生自我檢查的範本，按 **匯出 class.json**。

學生套用方式（二選一）：

- **設定 → 匯入班級設定檔**，選擇 class.json。
- 把 class.json 放在網路上，給學生網址 `https://…/editor.html?class=class.json的網址`。

班級設定檔**不含任何 KEY**，但含老師 PIN 的雜湊，學生無法自行進入老師模式。
注意：這些限制都在學生的瀏覽器裡執行，懂技術的學生仍可能繞過，正式考試請搭配其他管理方式。

---

## 6. 擴充功能

在編輯器左下角加入官方擴充（畫筆、音樂、micro:bit……）或用網址載入的第三方擴充後，AI 就會自動認得這些新積木，可以直接要求「用畫筆畫一個正方形」。

## 7. 離線使用

用 Chrome／Edge 開啟過一次網站後，編輯器會自動存到電腦裡，沒有網路也能開啟。
離線時可以寫程式，但 AI 功能需要網路；若使用本機模型（Ollama，設定選「OpenAI 相容」），AI 也能離線使用。

## 8. 常見問題

| 狀況 | 解決方式 |
|---|---|
| 「KEY 無效或沒有權限」 | 檢查 KEY 是否貼完整、是否已啟用付費或額度 |
| 「無法連線」 | 檢查網路；生圖服務若不允許瀏覽器直接連線，請老師架設代理（見 `proxy/README.md`） |
| AI 產生的積木有錯 | AI 會自動修正兩次；仍失敗時換個說法或改用高階模型 |
| 額度很快用完 | 改用「省錢優先」策略，或選低階模型 |
